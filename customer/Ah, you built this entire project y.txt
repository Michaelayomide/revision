### 🚀 Key Value Propositions (What makes your code valuable)

When writing your Project Catalog description or your pitch, make sure to emphasize these high-end features you built into it:

1. **Secure Session Engine:** Full CSRF token protection on all critical actions (`cart_add`, `place_order`, product updates) making it safe from exploits.
2. **ACID Transaction Checkout:** A robust checkout system that uses database transactions (`beginTransaction`, `commit`, `rollBack`). If a server drops midway, inventory isn't lost and carts aren't broken.
3. **Admin Controls with Live File Handling:** Asynchronous image processing with instant frontend sandbox preview and 2MB automatic server-side validation.
4. **Zero Heavy Framework Dependencies:** Written in clean, lightweight, native PHP/PDO and vanilla Bootstrap. This means it can run smoothly on even the cheapest $2/month shared hosting plan.
